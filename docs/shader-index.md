# Shader and effect index (ice and frost)

A short list of sources the skill can suggest when a user asks for an ice effect. Always check the license of each source before copying code. Links are full URLs so they can be clicked.

## Shader libraries (code)

| Source | Type | What it has | License |
|---|---|---|---|
| https://github.com/GDQuest/godot-shaders | 2D and 3D | 2D glow, 2D dissolve, 2D outline, 2D palette swap, screen distortion (useful for sparkle, glow and crack-fade tricks) | MIT (code), CC-BY 4.0 (art) |
| https://github.com/Locker72/godot-shaders | 2D and 3D | 2D dissolve, 2D glow, 2D outline, force field, distortion | Check the repository |
| https://github.com/jrassa/godot-shaders | 2D and 3D | Ported from the GDQuest set, with playable demos | Check the repository |
| https://github.com/deertears/deertears-godot-shaders | 2D particles | Shader experiments for 2D particles | Check the repository |

## Ready-made ice shaders (Godot Shaders site)

| Shader | Type | Link | Notes |
|---|---|---|---|
| Spatial Ice Shader | 3D | https://godotshaders.com/shader/spatial-ice-shader/ | Port of a Unity ice shader. Code is marked CC0 on the page. |
| Frostbite | Post-processing (screen) | https://godotshaders.com/?p=16390 | Frosted glass with cracks. Good for a "frozen screen" effect. |
| All ice-tagged shaders | Mixed | https://godotshaders.com/shader-tag/ice/ | Includes 2D reflective ice and Ice Covering (2D). |

## Reference shapes (not stored here)

Shape references such as crystal clusters, icicles, cracked blocks and shatter bursts can be found in icon or VFX sheets. Do not copy third-party sheets into this repository. Describe the shape in words, or link to the page where the sheet is sold or shared.
